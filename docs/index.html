What's different from Mihon

TurboMihon tracks upstream Mihon closely and pulls in every release automatically. On top of that, it carries a small set of its own features.

🌓

E-ink reader mode

Forces grayscale rendering and disables page transitions, the color overlay, and custom brightness — built for e-ink tablets where those effects just cause ghosting.

⬇️

Per-source download concurrency

Override the global parallel download and page limits on a per-source basis, so a self-hosted backend (like a Suwayomi server on your own network) isn't throttled to the same limits as a public source.

🏷️

Curated-pick chapter filter

Filter a chapter list down to chapters a source has tagged as the "curated pick" — useful for dedup workflows where multiple scanlator groups upload the same chapter and you only want the winner in your reading queue.

🔄

Automatic upstream sync

A daily job merges the latest Mihon release into this fork automatically, resolves the recurring version conflict, and opens a PR — so TurboMihon rarely falls more than a day behind upstream.

Downloads

Pulled live from the latest GitHub release. Pick the build matching your device's CPU architecture, or the universal APK if you're not sure.

About this fork

TurboMihon is a personal fork maintained for one person's own devices and workflow. It vendors upstream Mihon wholesale and re-syncs daily, keeping fork-specific changes small and self-contained. Source is on GitHub, licensed the same as upstream Mihon (Apache License 2.0).

Not affiliated with the Mihon project. TurboMihon is an independent, unofficial fork.
